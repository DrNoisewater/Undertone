# Working name shortlist

Undertone is a placeholder throughout this source preview. Suggested alternatives:

- Aside — short and understated, tied to speaking.
- Murmur — quiet, memorable, suited to a tray app.
- Cadence — natural speech and rhythm.
- Sotto — compact, with a musical feel.
- Relay — thoughts passed directly into your work.
- Hushline — a distinctive private-voice feel.
- Saywell — friendly, clear utility.
- Undertone — suits the graphite/copper design.

Favorites: Aside, Murmur, Undertone. Availability has not been checked. A final rename should cover app IDs, package names, installer metadata, user-data migration, icons, UI and documentation together.
